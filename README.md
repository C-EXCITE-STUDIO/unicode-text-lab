# 字樣工坊 · Glyph Studio

**v0.2.0｜B 方案：本地、離線、可複製的 Unicode 字樣工坊。**

## 開始使用

1. 如果使用 ZIP，先把整個壓縮包解壓縮；不要在壓縮包內直接執行。
2. 雙擊 **`啟動字樣工坊.cmd`**。
3. 瀏覽器會開啟本機頁面，預設為 <http://127.0.0.1:8787/>。
4. 輸入文字，在「組合工作台」選擇基底與裝飾，按「複製組合」。
5. 「字樣目錄」可按類型瀏覽；卡片可加入相應層，也能按「原樣複製」直接使用既有單項效果。星號可收藏單項字樣。

**不要直接雙擊 `web/index.html`**：ES modules 與本地資料載入需要 HTTP。

啟動服務的命令列視窗需要保留；在該視窗按 Ctrl+C 或將其關閉可停止服務。只關閉網頁不會停止服務。同一份專案已在執行時會重用既有服務，此時停止服務需回到原先啟動的視窗。連接埠被其他程式占用時會向後尋找可用連接埠，以啟動視窗顯示的網址為準。

### 環境需求

- 新版 Chrome／Edge，需支援 `Intl.Segmenter`。
- Python 3.10 或以上；本包**不捆綁 Python 執行環境**。
- Windows 啟動器優先尋找 `%LOCALAPPDATA%\hermes\tools\python-*\python.exe`，因此此電腦可使用 Hermes 已附帶的 Python；之後依序嘗試 PATH 中的 `python3`、`python`、`py -3`。
- 日常使用不需要 Node、npm、套件安裝或網際網路。Node 僅用於開發測試。

也可以手動執行：

```bash
python3 start.py
# 不自動開瀏覽器，或指定其他本機連接埠：
python3 start.py --no-browser --port 8787
```

## 分類與數量

| 分類 | 項目數 | 功能 |
|---|---:|---|
| 特殊字體 | 74 | 字母／數字外形替換，作為組合基底 |
| 表情／圖案 | 30 | 句首尾包邊 11 項、字間圖案／間隔 19 項 |
| 括號／邊框 | 8 | 整段括號、成對邊框或逐字框 |
| 疊加標記 | 20 | 底線、刪除線、重音與故障字等 |
| 純符號 | 5 | 完全獨立的圖案／符號字元映射，提供鍵位表 |
| 文字工具 | 15 | 大小寫、反轉、羅馬數字、摩斯與二進位編碼等 |
| 組合預設 | 14 | 可拆成基底與裝飾的既有配方 |
| **合計** | **166** | **既有字樣／效果定義數，不是 166 套獨立字體** |

原始四套候選資料以固定 38 組輸入的輸出指紋去重，等價來源記錄在 aliases。這是有限測試集的去重，不代表對所有可能字串都數學等價。本版重新分類，但保留原有 ID、原始步驟、來源與收藏識別碼，沒有把排列組合灌成新的字體數。

「合併相同結果」只合併**同一語義類型**在當次輸入的相同輸出，不會因中文未換字就把純符號與特殊字體混成同一卡。結果數隨輸入、類別與合併開關改變；取消合併並選「全部」可瀏覽所有 166 項。

## 分層組合怎麼用

基底單選普通文字、特殊字體、純符號或文字工具。非純符號模式另有四個獨立層：**句首尾表情／圖案、括號／邊框、字間圖案／間隔、底線／疊加標記**。每層最多一項，均可選「不添加」。選取組合預設會拆成可調整的配方；選單一元件則更新對應層。

例如輸入 `Ab`，選粗草寫、櫻花包邊、東方括號、火焰間隔及底線：

```text
🌸 【𝓐̲🔥𝓫̲】 🌸
```

固定從原文重新計算，順序為：**基底 → 標記 → 逐字框（若選）→ 字間圖案 → 整段框（若選）→ 句首尾圖案**，不是對已換字的結果再盲目套字體。組合模式會把部分舊效果整理為規則一致的元件；原始單項仍可直接複製。

### 純符號完全獨立

- 換入純符號時，四個裝飾選項全部清空並停用。
- 不能加括號、表情、字間圖案、底線或故障標記；核心組合器也會拒絕，不只是控制項變灰。
- 裝飾卡片的加入操作也不可用；換回普通文字或字體後才能組合。
- 按「鍵位對照」，可搜尋輸入字元、圖案或 `U+270C` 等 Unicode 碼位，並複製單個圖案。
- 表格依**實際轉換**產生，包含大小寫、多字輸入鍵與同圖案的多個來源字元；例如圖案符號字形的 `A → ✌`、`a → ♋` 不同。
- 請使用表中所列半形輸入字元；大寫可用 Shift／Caps Lock。這是字元對照，不是固定實體鍵盤位置圖。

漢字沒有對應整套哥德／草寫 Unicode 字母。字母替換通常保留漢字，可另加圖案與括號；仿日文／盧恩等樣式只是外形混搭，**不是翻譯**。

## 已有功能

- 即時預覽、中英文搜尋、分類篩選、分批載入。
- 單項複製、複製全部符合篩選的結果。
- 收藏、淺深色、預覽字級、相同輸出合併。
- 收藏及偏好的 JSON 匯出／匯入；匯入會合併收藏。

- 自動複製失敗時提供手動複製視窗，不冒充複製成功。

## 隱私與備份

所有轉換都在瀏覽器執行；伺服器只提供本地靜態檔案。輸入原文不寫入儲存或備份，**當前組合配方也只留在本次頁面**。收藏仍管理單項字樣，未加入組合收藏編輯器。瀏覽器只保存五個收藏／偏好欄位：`favorites`、`theme`、`fontSize`、`group`、`dedupe`。原有 `glyph-studio:v1` 備份格式保留，舊分類偏好會遷移。

收藏保存在這個瀏覽器的這個本機網址。改用另一個瀏覽器或連接埠時不會自動共享，請先匯出備份。清除網站資料可能清除收藏。

頁面正常載入與轉換不會發出外部請求；主動點擊來源網站連結時才會開啟線上網站。授權全文另有本地副本。

伺服器僅綁定 `127.0.0.1`，不向區域網路提供服務。它只公開 `web/`，不公開原始碼、`.git` 或目錄清單；有 Host 驗證及 CSP 等安全標頭。手機版面指小螢幕排版，不表示手機能連到這台電腦的 loopback 位址。

## Unicode 安全行為與限制

介面固定使用安全模式：以 grapheme cluster 處理反轉與間隔，保護旗幟、膚色、家庭 ZWJ、按鍵 emoji 與組合重音；不對 emoji／空白添加疊加標記，Zalgo 每字最多新增 12 個標記。空輸入不產生空裝飾框，超範圍羅馬數字段保留原字串。

相容模式僅供上游基準測試使用。因以上安全規則，產品模式對部分複合字元、空字串與數字段的結果會刻意不同於上游。

輸入上限為 4,000 個 UTF-16 文字單位；預覽每張最多顯示 180 個 grapheme，複製保留完整結果。超長輸出會明確報錯。

顯示取決於裝置字型，社群平台可能拒絕某些字元；目前沒有逐一驗證 Instagram／X／微信等平台。重要資訊請保留普通文字版本，花體也可能影響搜尋與讀屏器。

```bash
npm test
```

```bash
node --test tests/*.test.mjs
```
